# Security-Camera
Dear user,

This project is meant to detect faces and real individuals using a webcam connected to a jetson. Utilizes Python in Visual Studio code, it can also detect other basic objects such as computers an keyboards. Can be used to monitor classrooms and hallways. I did this due to the fact of the growing problems in the world with surveillance and the unexpected horrible catastrophes that appear globally. This project gives the user the "better safe than sorry" mindset while being equipped with responsibility and awareness.
